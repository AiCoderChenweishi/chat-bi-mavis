06关键 SQL 示例(复购率)

agent 生成的真实可执行 SQL,5 项自检全过

-- 复购率: 近 30 天下过 ≥2 单的用户 / 总下单用户
WITH user_orders AS (
    SELECT
        user_id,
        COUNT(DISTINCT order_id) AS order_cnt
    FROM dwd_trade_order
    WHERE pay_time >= CURRENT_DATE - INTERVAL 30 DAY
      AND order_status IN ('paid', 'finished')
      AND is_mock = TRUE
    GROUP BY user_id
)
SELECT
    COUNT(*) AS total_buyer,
    SUM(CASE WHEN order_cnt >= 2 THEN 1 ELSE 0 END) AS repeat_buyer,
    ROUND(SUM(CASE WHEN order_cnt >= 2 THEN 1 ELSE 0 END) * 1.0
          / NULLIF(COUNT(*), 0), 4) AS repurchase_rate
FROM user_orders;

07踩过的坑(DuckDB 细节)

开发中遇到,记录防止再踩

❌ DuckDB 没有 ELT()
用数组字面量取下标: ['A','B','C'][n % 3 + 1]
❌ CHAR(N) 不接受算术
改用 CHR(CAST(N AS INTEGER))
❌ UNNEST 只能接 1 个 array
多 array → 拆 3 个 subquery 再 cross join
❌ DECIMAL(6,2) 装不下 33992%
同比/ROI 字段给 DECIMAL(10,2) 余量
❌ LLM 返回 None 引爆 server
多层 try/except + data is None 兜底到 mock
❌ SQL 注释 -- 开头被拦截
判 SELECT 前先 strip 掉 -- 注释行
